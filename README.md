
# ONEBITE - Food Ordering Website

## Project Overview
ONEBITE is a food ordering website with Admin and Client sections.

## Project Structure
- Admin: Admin dashboard, login, customer management, food management and orders.
- Client: Home page, menu, cart, checkout and feedback pages.
- Images: Food and website images.

## Technologies Used
- HTML
- CSS
- Bootstrap
